# Responsible Use Policy

NetLens is an educational networking project designed solely for learning how basic TCP connect() sockets work in C.

## Scope of Acceptable Use
- **Private Networks:** You may only run this software on RFC 1918 local private networks (e.g., `192.168.x.x`, `10.x.x.x`).
- **Owned Hardware:** You may only scan devices, servers, or virtual machines that you personally own or have explicit, documented authorization to test.
- **Educational Labs:** It is designed for isolated lab environments to understand network programming concepts.

## Prohibited Actions
You may not use this tool for:
- Scanning public IP addresses or networks you do not own.
- Malicious reconnaissance, vulnerability probing, or exploitation.
- Disruption of services, denial-of-service, or bypassing access controls.
- Any illegal or unauthorized activities.

By using this software, you agree to abide by these rules and take full responsibility for your actions.
